# 핀맵 · Pinmap

핀맵은 여러 곳에 저장해 둔 콘텐츠를 장소와 연결해, 필요할 때 지도에서 다시 발견할 수 있도록 돕는 서비스입니다.

## 해결하려는 문제

SNS에서 발견한 장소 게시물을 저장해도 시간이 지나면 게시물 속 장소를 다시 찾기 어렵습니다. 저장한 콘텐츠와 실제 방문할 장소 사이를 잇는 탐색 경험을 만들고자 합니다.

## 서비스의 흐름

1. **콘텐츠 저장** — 관심 있는 게시물이나 링크를 모읍니다.
2. **장소 정리** — 콘텐츠에 소개된 장소와 관련 정보를 연결합니다.
3. **지도 탐색** — 장소를 지도에서 살펴보고 원본 콘텐츠의 맥락을 다시 확인합니다.
